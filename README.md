# Compute from Scratch

GPT-6.1 Solが、ベアメタル環境で機械語からどこまでソフトウェアスタックを構築できるかを観察する実験。

## 起動テスト

Python 3と `qemu-system-aarch64` が必要。macOSでは `brew install qemu` で入手できる。

```sh
run=$(python3 runner.py fixtures/serial-smoke.hex)
cat "$run/serial.log"
```

`O` と改行が出れば成功。サンプルは出力後にループするので、既定の2秒でランナーがQEMUを停止する。各実行のバイナリ、シリアル、QEMUの標準エラー、実行条件は `.local/runs/` に保存する。

## 初回の実験条件

- QEMU `virt`、Cortex-A53、1コア、TCG、RAM 64 MiB。ランナーは16進バイト列をデコードし、物理アドレス `0x40200000` に配置してCPU 0のPCをそこに設定する。
- エージェントには起動契約とデバイス構成だけを渡す。命令表、レジスタ仕様、サンプルコード、スモークテスト用のバイナリは観測側に置く。
- 目標はPL011のシリアル出力、ゲスト発のTCPエコー、ホストのHTTP GETレスポンス本文の表示、取得したHTMLの画面描画の順。
- NICと画面は無効。ネットワークと描画の実験は後続の段階で追加する。

実験記録は [Piでの初回試行](experiments/001-pi-boot.md) から始める。本番ではエージェントにリポジトリ全体を公開せず、実験専用の成果物領域と許可した操作だけを渡す。

## Piでゼロから始める

Node.js 24、Python 3、QEMU、ログイン済みのCodex CLIが必要。Pi SDKはCodexの有効なアクセストークンを観測側でメモリに読み込み、更新はCodexに任せる。

```sh
npm ci --prefix pi --ignore-scripts
node pi/run.mjs
```

毎回、空の作業ディレクトリと新規セッションを作る。プロンプトとシステム設定、モデルのメッセージ、ツールの呼び出しと結果を `.local/experiments/pi-*/` に残す。初期ステージは `run_guest` のみ。16進バイト列でVMを1秒間起動し、シリアル出力の先頭4 KiBと実行IDを返す。過去の実験記録やバイナリは観測側に保管する。

| ステージ | モデルに公開する操作 |
| --- | --- |
| シリアル出力 | 生バイト列でVMを起動し、シリアル出力を読む |
| 対話入力 | VMを維持し、ゲストにシリアル入力を送る。画面操作が必要になったらキー入力を追加する |
| TCP・HTTP | 指定のホストサービスに限って通信できるNIC構成でゲストを起動する |
| HTML描画 | ゲストの画面を取得する |

新しい操作を追加するときは、そのステージのツール一覧とゲスト構成を実験記録に残す。
