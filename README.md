# Compute from Scratch

GPT-6.1 Solが、ベアメタル環境で機械語からどこまでソフトウェアスタックを構築できるかを観察する実験。

## 起動テスト

Python 3と `qemu-system-aarch64` が必要。macOSでは `brew install qemu` で入手できる。

```sh
run=$(python3 runner.py fixtures/serial-smoke.hex)
cat "$run/serial.log"
```

`O` と改行が出れば成功。サンプルは出力後にループするので、既定の2秒でランナーがQEMUを停止する。各実行のバイナリ、シリアル、QEMUの標準エラー、実行条件は `.local/runs/` に保存する。

## 初回の実験条件

- QEMU `virt`、Cortex-A53、1コア、TCG、RAM 64 MiB。ランナーは16進バイト列をデコードし、物理アドレス `0x40200000` に配置してCPU 0のPCをそこに設定する。
- エージェントには起動契約とデバイス構成だけを渡す。命令表、レジスタ仕様、サンプルコード、スモークテスト用のバイナリは観測側に置く。
- 目標はPL011のシリアル出力、ゲスト発のTCPエコー、ホストのHTTP GETレスポンス本文の表示、取得したHTMLの画面描画の順。
- 現在のランナーは観測側が使う。NICと画面は無効。専用ツール経由でのモデル接続と、指定のホストサービスだけに到達できるネットワークは次の段階で追加する。

観測側の記録は [experiments/](experiments/) に置く。本番ではエージェントにリポジトリ全体を公開せず、実験専用の成果物領域と許可した操作だけを渡す。
