# 001 — Piでゼロからシリアルを起動

2026-11-04 JST。Pi SDK 1.5.0、GPT-6.1 Sol、QEMU 11.1.2。

空の作業ディレクトリと新規セッションを使用し、過去の会話、コード、資料を渡さなかった。[初期プロンプト](001-pi-prompt.txt)と固定のシステム指示を渡し、Piの有効なツールが `run_guest` だけであることをセッション開始前に確認した。

1. モデルが独自に作ったプローブを実行し、`?\n` を観測した。実行IDは `20261103T210631.203055Z`。
2. モデルが新しいイメージを実行し、`PI BOOT\n` を観測した。実行IDは `20261103T210642.223781Z`。観測側でもシリアルログをバイト単位で比較し、一致を確認した。

途中の介入はなかった。今回は両方のゲスト実行が成功した。Pi接続の準備ではAPIキー形式での認証が通らず、既存Codexのアクセストークンをメモリ内のOAuth資格情報として扱う構成で接続できた。

生ログは `.local/experiments/pi-epm0Xj/` と `.local/runs/` に保存した。[最終イメージ](001-pi-boot.hex)は観測側から再実行できる。
