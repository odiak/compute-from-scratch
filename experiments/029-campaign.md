# 029 — ロード済みプログラムに argc と argv を渡す

2026-11-04 JST。[ステージ指示](029-campaign-prompt.txt)に沿って、シェルに `exec PROGRAM [ARG ...]` を追加した。ロード済みプログラムは、コンソール出力用コールバック、引数の個数、NUL終端した文字列へのポインタ配列を受け取る。プログラム名を含めて最大8トークンで、戻り値は従来の `run` と同じ形式で表示される。

観測側は、ゲストで組み立てた同一のプログラムに1、4、8トークンを渡した。コンソール出力コールバックを挟んでも引数の内容と順序が保たれ、配列の末尾がヌルポインタであることを確認した。プログラム未ロード時、名前なし、トークン数超過は拒否され、直前のロード済みプログラムは再び実行できた。従来の数値引数、プロセス入出力、リンク移動、8 KiBの実行コード、Cの配列も検証を通った。

[ゲストアセンブリ](029-exec.s)を別のVMで組み立てた結果は、[最終イメージ](029-campaign.hex)の追加356バイトと一致した。キャンペーンのディスクは開始前のスナップショットとバイト単位で一致した。続行指示は0回。

再現は `python3 verify_exec_argv.py experiments/029-campaign.hex`。[引き継ぎメモ](029-handoff.txt)と[トランスクリプト](029-transcript.md)を保存した。
