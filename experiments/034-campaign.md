# 034 — Cコンパイラの自己ホスト

2026-11-04 JST。[ステージ指示](034-campaign-prompt.txt)に沿って、Piは[段階032の種コンパイラ](032-seed.s)が扱えるCで[新しいコンパイラ](034-compiler.c)を書いた。種でコンパイラを作り、それをインストールして同じCソースをビルドし、次の世代でもう一度ビルドした。すべてゲスト内で実施した。

| 生成に使ったコンパイラ | 生成物のサイズ |
| --- | --- |
| アセンブリで書いた種 | 24,628バイト |
| 種からビルドしたC製コンパイラ | 19,040バイト |
| 自分のソースをビルドしたC製コンパイラ | 19,040バイト |

観測側はQMPで各世代を取り出し、後ろの2世代がバイト単位で一致することを確認した。SHA-256は `b2a0d14e6c99b9e23f819ec5818daba8bf74409dda5ef01a1dcca1face81696e`。最終世代で、ランダムな関数名、複数引数、ローカル変数、ループを含む別のCソースをビルドした。複数の実行時引数で結果を照合し、失敗したビルドが直前の実行ファイルを維持することも確認した。

通信切断後、観測結果を渡して続行を1回依頼した。段階033のカーネルと保護対象の19ファイルはバイト単位で一致した。コンパイラの対応範囲は、整数、文字・整数ポインタ、最大4引数の関数、変数、分岐、ループなど。標準ライブラリやプリプロセッサは今後の作業となる。

再現は `python3 verify_self_compiler.py experiments/033-campaign.hex experiments/032-seed.s experiments/034-compiler.c`。[言語仕様と操作手順](034-handoff.txt)、[トランスクリプト](034-transcript.md)を保存した。
