Editor: p [N], i N text, r N text, d N, w saves, q discards changes after the last save. A failed build retains the last successful USER, including across editor/pipeline operations. build pins USER; exec supplies argv0/arguments. A bare source name compiles/runs in a separate transient slot. @NAME loads an arbitrary saved binary through the same descriptors/pipeline; there are no cat/echo/basename-specific adapters.
Operators are whitespace-separated < > >> 2> |; quotes preserve spaces, without escape/variable/glob expansion. Pipes are sequential, max8 stages and32768 bytes per hop; first failure stops subsequent stages. Input redirects belong to the first stage, output redirects to the last. Existing output writes are not transactional.
